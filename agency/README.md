# /agency — ClearSite Digital (new business workspace)

Planning material and a landing-page prototype for a new NZ business: an SEO agency
and website builder for glaziers and related construction trades.

- `BUSINESS-BRIEF.md` — naming, positioning, pricing, go-to-market, next steps.
- `site/index.html` — self-contained landing page prototype (open directly in a
  browser; no build step needed).

This folder is **not** part of the Balustrading Concepts production site. Vite only
builds from the repo root's `index.html`/`src`, so nothing here ships to
balustrading.co.nz. When the new business gets its own repo/Cloudflare Pages project,
move this folder there.
